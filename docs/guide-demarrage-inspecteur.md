# Guide de démarrage rapide — c3-digital

**Pour l'inspecteur qui utilise l'application pour la première fois sur le terrain.**
*(Pilote de Butembo, Nord-Kivu 2 — 1 page, à imprimer ou garder sur le téléphone)*

---

## 1. Installer l'application

1. Recevez le fichier **`app-release.apk`** (clé USB, WhatsApp, ou autre — remis par l'IGE).
2. Sur votre téléphone Android, ouvrez le fichier reçu.
3. Si un message demande d'autoriser **"Sources inconnues"** ou **"Installer des applications inconnues"**, acceptez — c'est normal pour une application distribuée hors du Play Store pendant le pilote.
4. Appuyez sur **Installer**, puis ouvrez l'application **c3-digital**.

> Pas besoin d'internet pour installer ni pour utiliser l'application au quotidien.

## 2. Remplir un formulaire (aucun compte requis)

L'écran d'accueil affiche les **5 formulaires** IGE : C2, C3, C3B, C3M, C3_DAS.

1. **Touchez le formulaire** que vous voulez remplir.
2. **Identification** : nom de l'inspecteur, établissement, enseignant, année scolaire... Remplissez puis appuyez sur **Suivant**.
3. **Chaque section** : notez chaque critère de **0 à 4**, puis **Suivant**. Un bouton **"Suggestion IA"** peut reformuler vos notes en conseil pédagogique si vous êtes connecté à internet — sinon, continuez sans, ce n'est jamais obligatoire.
4. **Synthèse et signatures** : vérifiez le score et la mention, faites signer avec le doigt (enseignant, chef d'établissement, inspecteur), puis appuyez sur **Générer le PDF**.
5. Appuyez sur **Terminer** — le formulaire est enregistré sur le téléphone.

## 3. Le mode hors-ligne — ne vous inquiétez pas

- L'application fonctionne **entièrement sans connexion internet**, du début à la fin.
- Le bandeau en haut de l'écran indique l'état : **"Hors-ligne"** ou **"Synchronisé"**.
- Rien à faire manuellement : dès que le téléphone retrouve une connexion (réseau mobile ou Wi-Fi), l'envoi vers le serveur se fait **tout seul**, en arrière-plan.
- **Aucune donnée n'est perdue** si vous fermez l'application ou éteignez le téléphone — tout est sauvegardé automatiquement à chaque étape.

## 4. Compte, abonnement et PDF (optionnel)

- L'icône **"Profil"** (en haut à droite de l'écran d'accueil) permet de se connecter, de voir son abonnement (essai gratuit de 14 jours), et de choisir une formule de paiement (M-Pesa, Orange Money, Airtel Money, carte).
- Après **"Générer le PDF"**, vous pouvez le consulter, le partager ou l'imprimer comme n'importe quel document sur votre téléphone.

## En cas de problème

- **Rien ne s'affiche / erreur au chargement** : fermez et rouvrez l'application.
- **Pas de réseau sur le terrain** : continuez normalement, la synchronisation se fera plus tard.
- **Besoin d'aide** : contactez l'équipe IGE du pilote de Butembo (Nord-Kivu 2).
