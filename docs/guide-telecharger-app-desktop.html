Récupérer l'installateur Windows

GitHub construit le fichier pour vous — 4 étapes, une seule fois pour l'activation

Je ne peux pas déposer de fichier ici même : l'installateur Windows doit être construit sur un ordinateur Windows, et je n'en ai pas dans mon environnement. GitHub, lui, en a — la suite explique comment lui demander de le construire à votre place, gratuitement, puis comment récupérer le résultat.

  1. 1

    Activer la construction automatique (une seule fois)

    Ouvrez les réglages Actions du dépôt, choisissez Allow all actions and reusable workflows, puis Save en bas de page.

    github.com/.../settings/actions
  2. 2

    Lancer la construction

    Sur l'onglet Actions, cliquez le nom du workflow voulu dans la liste à gauche (voir les deux choix ci-dessus), puis le bouton Run workflow (menu déroulant en haut à droite de la liste des exécutions) → Run workflow à nouveau pour confirmer.

    github.com/.../actions
    Patience — la construction prend 5 à 15 minutes (elle recompile l'application pour Windows, macOS et Linux en même temps). Un rond orange tourne pendant ce temps ; il devient une coche verte ✓ une fois terminé.
  3. 3

    Télécharger le résultat

    Une fois la coche verte affichée, cliquez sur cette exécution pour l'ouvrir, puis descendez tout en bas de la page jusqu'à la section Artifacts. Cliquez sur celui qui contient windows dans son nom pour télécharger un fichier .zip.

  4. 4

    Installer sur Windows

    Décompressez le .zip téléchargé, puis ouvrez le fichier .msi ou .exe qu'il contient.

    Normal — Windows affichera probablement "Windows a protégé votre ordinateur" (l'installateur n'est pas encore signé numériquement, comme pour l'APK Android pendant le pilote). Cliquez Informations complémentaires puis Exécuter quand même pour continuer l'installation.
